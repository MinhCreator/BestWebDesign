03

Features

12 items

Everything ENDURANCE|HUB does — from a video hero to an admin dashboard with real-time system health.

🎬 Video hero
Full-width background video with community stats overlay. Gradient overlay transitions from light to transparent.
HomeMotion
🪟 Glassmorphism navbar
Sticky nav with backdrop blur, responsive hamburger menu, active-route highlighting with blue underline.
UIResponsive
🏆 Leaderboard
Top-3 podium with avatar, flag display, ranked table with trend arrows. Animated with Motion.
RankData
🗺 Event listing + map
Filterable event cards by type, distance, location. Embedded Google Map. Paginated grid view.
EventMap
📝 Registration form
Multi-section form with validation, left/right layout, dialog confirmation. Form components are reusable.
FormValidation
📰 News sidebar
Articles fetched from Python scraper (irace.vn). Main content + side panel layout. Auto-refresh.
NewsScraper
💡 Paginated tips grid
Animated grid of training tips from /api/posts/. Pagination controls. TanStack Query caching.
TipsQuery
👥 Community section
Club cards, forum link, activity feed. Connected to backend for dynamic content.
HomeSocial
🏋️ Training tools
Training plan poster, pace calculator, progress analysis. Interactive tools for athletes.
TrainingTools
👤 Team page
4-member grid with avatars, roles, social links. Public-facing profiles for core team.
TeamAbout
🔐 Admin dashboard
Protected login, dashboard stats, CRUD for registrations, events, content. Token-based auth.
AdminAuth
⚙️ System health
Admin panel with system health monitoring, cache controls, user management, and crawl triggers.
AdminOps
