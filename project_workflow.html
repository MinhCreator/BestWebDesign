Architecture

Component tree, data flow, and how the pieces connect from the browser to the serverless proxy and private backend.

Solid = request/response. Dashed = lazy-loaded page or external system. Vite dev server proxies /api to 127.0.0.1:8000; Vercel uses api/proxy.js for production.

03

Features

17 items

Everything ENDURANCE|HUB does — from a video hero to an admin dashboard with user management and system health.

🎬 Video hero
Full-width background video with community stats overlay. Gradient overlay transitions from light to transparent.
HomeMotion
🪟 Glassmorphism navbar
Sticky nav with backdrop blur, responsive hamburger menu, active-route highlighting with blue underline.
UIResponsive
🫧 Bubble navbar
Secondary floating navigation with pill-style bubbles for quick access to key sections.
UINavigation
🏆 Leaderboard
Per-event dynamic leaderboard. Top-3 podium with avatars, flags, sorted ranked table. Linked from event cards via /Leaderboard/:eventId. TanStack Query caching.
RankDynamic
🗺 Event listing + map
Filterable event cards by type, distance, location. Embedded Google Map. Paginated grid view.
EventMap
📝 Registration form
Multi-section form with validation, left/right layout, dialog confirmation. Form components are reusable.
FormValidation
📰 News sidebar
Articles fetched from Python scraper (irace.vn). Main content + side panel layout. Auto-refresh.
NewsScraper
💡 Paginated tips grid
Animated grid of training tips from /api/posts/. Pagination controls. TanStack Query caching.
TipsQuery
👥 Community section
Club cards, forum link, activity feed. Connected to backend for dynamic content.
HomeSocial
🏋️ Training tools
Training plan poster, pace calculator, progress analysis. Interactive tools for athletes.
TrainingTools
👤 Team page
4-member grid with avatars, roles, social links. Public-facing profiles for core team.
TeamAbout
🔐 Admin dashboard
Protected login, dashboard stats, CRUD for registrations, events, content. Token-based auth with ProtectedRoute guard.
AdminAuth
👥 Admin users
User management panel with role-based access (superadmin required).
AdminUsers
📋 Admin events
CRUD management for events from the admin panel.
AdminCRUD
🏅 Results management
Per-event runner results CRUD. Add/edit/delete runner entries with time, nationality, and avatar URL. Powers the dynamic leaderboard.
AdminCRUD
⚙️ System health
Admin panel with system health monitoring, cache controls, user management, and crawl triggers.
AdminOps
📱 Responsive design
Mobile-first responsive layout with glass cards, gradient text, and consistent design system throughout.
UIDesign
