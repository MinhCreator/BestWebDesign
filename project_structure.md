## Project Structure
The project is divided into several folders:
- `src`: This folder contains the source code for the application.
- `public`: This folder contains static assets that can be served directly by the web server.
- `api`: This folder contains the proxy server code that fetches data from the private API.

## Folder Description
- `src/components`: This folder contains the React components for the application.
- `src/views`: This folder contains the views for the application.
- `src/hooks`: This folder contains the custom hooks for the application.
- `src/api`: This folder contains the API routes for the application.
- `public/index.html`: This is the main entry point for the application.
- `public/favicon.ico`: This is the favicon for the application.
